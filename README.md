# 🌿 Hoeun Sophanut — Developer & Designer Portfolio

A modern, responsive personal portfolio website built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**. Designed with a curated **Forest Green (`#143826`)** and **Golden Amber (`#ffaa00`)** aesthetic, featuring smooth micro-animations, full dark/light mode switching, and clean modular component architecture.

---

## ✨ Features & Highlights

- 🌓 **Seamless Dark & Light Themes** — Persisted in `localStorage` with a blocking script in `index.html` to eliminate Flash of Unstyled Content (FOUC).
- 🪐 **Orbital Skill Pills Animation** — 5 skill tags orbit around the profile photo in the About section with counter-rotation to keep typography upright.
- ⚡ **Infinite Seamless Marquee** — Hardware-accelerated `translate3d` continuous right-to-left scrolling skill ticker.
- 💼 **Interactive Service Cards & Detailed Modals** — High-contrast service items with custom PNG icons and comprehensive scope overview modals.
- 📁 **Filterable Projects Showcase** — Categorized by Web Development, App Solutions, and UI/UX Design with detailed project modals, tech badges, and direct Live Preview / GitHub links.
- 🎓 **Interactive Journey Timeline** — Tabbed switch between Education milestones (RUPP) and Professional Work Experience.
- 💡 **Animated FAQs Accordion** — Smooth height-animated expand/collapse with numbered items and high-contrast toggle controls.
- 📬 **Validated Contact Form** — Clean, theme-adaptive text fields with custom alerts and direct contact channels.
- 🌐 **Real-World Social Logos** — Standalone official vector logos for GitHub, LinkedIn, Telegram, and Facebook.

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/henboddy87-blip/Real-Portfolio.git
   cd Real-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Production Build

To build the production bundle:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
